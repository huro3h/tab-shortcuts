# Tab Shortcuts

タブ操作と選択テキスト検索を、キーボードショートカットで実行するための拡張 (MV3)。
Chrome が右クリックメニューにしか持っていない操作 (他のタブを閉じる・ピン留めなど) と、
Chrome にもともと無い操作 (すべてのウィンドウを1つに統合・すべてのタブをリロード) に加えて、
Chrome 本体ではキーを変えられない「右/左のタブへ移動」を好きなキーに割り当てられます。

## できること

| コマンド | 内容 | 初期ショートカット |
| --- | --- | --- |
| 他のタブを閉じる | アクティブタブとピン留めタブを残して、同じウィンドウの他のタブを閉じる | `⌥⇧O` |
| 右のタブを閉じる | アクティブタブより右のタブを閉じる。ピン留めは残す | `⌥⇧R` |
| タブのピン留めを切り替える | アクティブタブのピン留めをトグルする | `⌥⇧P` |
| すべてのウィンドウを統合 | 他のウィンドウのタブを、今見ているウィンドウに集める | 未割り当て |
| 選択テキストをGoogleで検索 (前面タブ) | 選択した文字列を検索し、隣のタブで開いて切り替える | `⌥S` |
| 選択テキストをGoogleで検索 (背面タブ) | 同上。タブは開くが切り替えない | 未割り当て |
| すべてのタブをリロード | 全ウィンドウのタブをまとめて再読み込みする | 未割り当て |
| タブのミュートを切り替える | アクティブタブのミュートをトグルする | 未割り当て |
| 右のタブへ移動 | 右隣のタブに切り替える。右端では左端へ回り込む | 未割り当て |
| 左のタブへ移動 | 左隣のタブに切り替える。左端では右端へ回り込む | 未割り当て |
| 右/左のタブへ移動 (2つ目のキー) | 上の2つと同じ動き。別のキーをもう1つ割り当てたいとき用 | 未割り当て |

ピン留めタブは「他のタブを閉じる」でも「右のタブを閉じる」でも**絶対に閉じません**
(Chrome 本体の右クリックメニューと同じ挙動)。

初期ショートカットが4つまでなのは Chrome の制限です (拡張1つにつき `suggested_key` は最大4つ)。
未割り当てのコマンドは下記の手順で好きなキーを設定してください。作者は
「すべてのウィンドウを統合」に `⌥⇧G`、「背面タブ検索」に `⌥⇧S` を割り当てています。

### すべてのウィンドウを統合について

- **タブグループは解体せずそのまま移動します** (名前と色も保たれます)。
- ピン留めタブはピン留めのまま、移動先のタブバー左端に入ります。
- シークレットウィンドウは、通常ウィンドウとの間で相互に吸い込みません
  (Chrome がこの境界を越えるタブ移動を許可していないため)。
- `window.open()` で切り出されたポップアップウィンドウは対象外です。
- タブが全部抜けたウィンドウは Chrome が自動的に閉じます。

### すべてのタブをリロードについて

- 通常のウィンドウすべてが対象です。ピン留めタブも再読み込みします。
- **Chrome がメモリ節約のために破棄 (スリープ) したタブは起こしません**。
  次に開いたときにどうせ読み直されるため、まとめて起こすとメモリと回線を使うだけになります。
- **シークレットウィンドウのタブは、通常ウィンドウから実行しても対象外です**
  (逆も同じで、シークレットから実行すればシークレットのタブだけが対象)。
  拡張に「シークレットモードでの実行を許可」を与えている場合でも、
  プライベートセッションの入力中フォームやログイン状態を巻き添えにしません。
- `window.open()` で開かれたポップアップウィンドウと、インストール済み PWA の
  アプリウィンドウは対象外です (ログインや決済のダイアログを踏み潰さないため)。
- 通常のリロードです (キャッシュを無視するスーパーリロードではありません)。

### 選択テキスト検索について

- 何も選択していないときは何もしません (空の検索タブを開きません)。
- iframe 内で選択した文字列も拾います。
- 検索タブは**元のタブのすぐ隣**に開き、閉じると元のタブに戻ります。
- `chrome://` などの内部ページや Chrome ウェブストアでは、拡張がページを読めないため動きません。
- **検索した文字列をクリップボードにもコピーします** (初期状態でオン)。コピーされるのは検索語と
  同じ、改行や連続した空白をスペース1つにまとめた文字列です。不要なら
  `chrome://extensions` の Tab Shortcuts の「詳細」→「拡張機能のオプション」でオフにできます。

### タブのミュートについて

- ミュートするのは**今のタブだけ**です。Chrome の右クリックメニューにある「サイトをミュート」
  (同じサイトのタブすべてに効く設定) とは別物です。サイト単位の操作には、インストール時に
  警告が出る権限 (`contentSettings`) が必要なため、この拡張では扱いません。

### 右/左のタブへ移動について

- Chrome 本体の `⌘⌥→` / `⌘⌥←` と違い、`chrome://extensions/shortcuts` で好きなキーを割り当てられます。
- 端のタブでは反対の端へ回り込みます。
- Chrome は1つのコマンドにキーを1つしか割り当てられないため、同じ動きのコマンドを
  「(2つ目のキー)」として別に用意しています。`⌥.` と `⌥→` のように2通りで押したいときに使います。
- **折りたたまれたタブグループの中のタブは飛ばします** (Chrome 本体の `⌃Tab` と同じ。
  通り過ぎるだけでグループが展開されてしまうのを防ぐため)。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ

## ショートカットの設定

`chrome://extensions/shortcuts` で変更・追加できます。コマンドは `01_` 〜 `12_` の順に並びます。

### 既存の拡張から乗り換える場合

`⌥⇧O` / `⌥⇧R` / `⌥⇧P` は
[Keyboard Shortcuts to Close Other/Right Tabs](https://chromewebstore.google.com/detail/keyboard-shortcuts-to-clo/dkoadhojigekhckndaehenfbhcgfeepl)、
`⌥S` は
[Shortcut keys for selection search](https://chromewebstore.google.com/detail/shortcut-keys-for-selection-search/emceciddhgnjkmjmpjoahmdhibmifohp)
と同じキーです。

**同じキーを使っている拡張を先にアンインストールしてから**この拡張を読み込んでください。
Chrome はショートカットの重複を許さないため、先に別の拡張が握っていると初期ショートカットが
無言で入りません。入れ替えの順番を間違えた場合は、`chrome://extensions/shortcuts` で
手動で割り当て直せば直ります。

## 権限

| 権限 | 用途 |
| --- | --- |
| `tabs` | タブの取得・削除・移動・ピン留め・ミュート・リロード |
| `tabGroups` | 統合時にタブグループを解体せずに移動する |
| `activeTab` | 検索コマンドを押した瞬間だけ、そのタブから選択テキストを読む |
| `scripting` | 上記の読み取りを実行する |
| `storage` | オプション画面の設定を保存する |
| `offscreen` | 検索語のコピーを、画面に出ない拡張内のページで行う (service worker からは直接コピーできないため) |
| `clipboardWrite` | 検索語をクリップボードに書き込む。読み取りはしない |

`activeTab` はショートカットを押した瞬間にだけ与えられる一時的な権限で、閲覧履歴や
他のタブの内容にはアクセスしません。

## 開発

ロジックは `planner.js` に純粋関数として切り出してあり、Chrome なしでテストできます。

```sh
node --test test/planner.test.mjs
```

`background.js` は `planner.js` が決めた結果を Chrome API で実行するだけの薄い層です。
